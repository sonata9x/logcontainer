# 공유 UI / 테마 / 로그 BGM 수정

## 구현

- 공유 멤버 권한 드롭다운에 시스템 폰트, 글자색, 줄높이, 여백을 명시했다. 등록 사용자·Guest의 제거 버튼은 X 아이콘만 남기고 테두리를 제거했다. 공유 권한 모델과 제거 권한 검증은 변경하지 않는다.
- 테마색이 workspace-shell에만 지정되어 body portal 팝업에서 기본색으로 돌아가던 문제를 수정했다. WorkspaceAppearance가 개인 accent를 body와 shell에 동기화하고, workspace 이탈 시 이전 값을 복구한다. 설정 저장 후 context를 갱신하여 다시 열 때도 최신 색상을 사용한다. primary 버튼 hover, 설정 탭, checkbox/radio/range에도 테마색을 적용한다. 위험 동작은 danger 색상을 유지한다.
- 메시지별 및 대기 BGM의 `내 BGM에 추가` 버튼을 제거했다. 편집·게시 화면 상단의 로그 `…` 메뉴에 `로그 BGM 전체 담기`를 제공한다. 페이지 꾸미기의 기존 prompt 기반 연동 생성 버튼은 제거했다.
- 전체 담기는 현재 페이지의 대기/메시지 BGM을 서버에서 전부 읽어 실제 곡(asset id)으로 중복 제거한 뒤 자신의 기존/새 플레이리스트에 복사한다. 기존 담긴 곡은 다시 넣거나 이름·순서를 덮어쓰지 않는다. 신규 곡은 마지막 순서 뒤에 추가한다. 페이지 조회와 대상 곡 조회는 각각 500행 단위로 페이징한다. 새 리스트는 source_page_id가 없는 독립 리스트이며 기존 연동 리스트/DB trigger는 그대로 보존한다.
- 사설 로그는 승인된 계정의 resource 열람 권한, 게시 로그는 활성 게시 및 비밀번호 session과 해당 page id 일치를 검증한다. 게시 로그에서 로그인한 사용자의 자신의 playlist를 확인한 뒤, 그 게시 페이지에서 읽은 곡에만 admin 복사를 제한한다. 사용자 입력으로 곡 목록/owner id를 받지 않는다. 비로그인·잠긴/잘못된/다른 페이지 게시 token은 거부한다. 새 리스트에 곡 등록이 실패하면 해당 신규 리스트 정리를 시도한다.
- 재생 아이콘은 테두리 없이 연한 회색 배경과 UI muted 글자색을 사용한다. 개별 버튼은 계속 entry id에 귀속된다.
- 편집 화면은 viewport 1100px 이하에서 개별 BGM 버튼을 숨긴다. 좁은 Guest 편집 화면도 동일하다. 게시/Guest 열람 화면은 숨기지 않으며 960px 이하에서 메시지 위의 단일 조작 행에 표시한다. 이 행은 편집 화면에 적용하지 않아 비어 있는 행이나 손잡이/사이드바 침범을 방지한다.

## 검증 및 제한

- 중복 곡/1201곡/원본 불변, 사설·게시 접근 결정, 잠긴/잘못된/다른 페이지 게시 거부, target owner 검증, 페이지 페이징, 재생 버튼 노출 범위, 공유 UI와 portal 테마의 회귀 테스트를 추가했다.
- 자동 테스트 172개 통과, ESLint 및 production build/TypeScript 통과. 삭제된 메시지·미확정/삭제된 음악은 전체 담기에 포함하지 않는다. 자동 테스트 및 코드 검사는 실제 모바일 픽셀/Native select 팝업 렌더링 검증을 대신하지 않는다. 이번 세션에는 이전 GPT 브라우저 제어 도구가 제공되지 않아 실제 게시/모바일 UI 조작 검증은 하지 못했다. 기존 개인 로그 내용이나 새 게시 링크는 생성·변경하지 않았다.
- 추가 SQL 실행은 필요하지 않는다. 기존 데이터/권한/음악 원본/연동 playlist는 유지한다.
