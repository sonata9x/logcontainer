# BGM 관리·편집 및 기본 테마 후속 수정

## 구현

- 사이드바에는 사이트 관리자에게 `관리` 하나만 표시. 관리 페이지 내부에서 계정/BGM 탭 이동, 현재 탭 색과 밑줄 및 `aria-current` 제공.
- 관리 BGM 제목 옆에 사용 상태/삭제 대기 및 업로드 24시간 영구 삭제 보호 표시. 좁은 화면에서는 제목 영역 내 줄바꿈.
- 전체 / 로그 미사용 / 보관함에만 존재 / 연결 없음 필터. 검색·필터 적용 후 DB에서 100개씩 페이지네이션.
- 로그 미사용은 페이지 연결이 없는 곡. 휴지통의 페이지·블록도 복구 가능하므로 사용 중으로 취급.
- BGM/플레이리스트 생성·이름 변경 및 플레이리스트 곡 선택은 페이지 팝업. MP3 업로드 이름도 기존 페이지 팝업 유지. 삭제 확인 등 요청 외 native confirm/alert는 유지.
- 개인 보관함 BGM 편집 팝업에서 YouTube 링크 변경. 이름은 개인 별칭이며 링크는 공유 원본. 링크 편집은 최초 업로더 또는 사이트 관리자만 가능; 복사한 곡은 링크 읽기 전용, 개인 이름 변경 가능.
- 링크와 이름 변경은 승인 계정 확인 및 자기 보관함 확인 후 DB 트랜잭션에서 처리. 자산→보관함 순서 잠금으로 영구 삭제와 충돌 보호. 권한 실패 시 이름 변경도 롤백.
- 같은 페이지에서 해당 곡이 재생 중이면 링크 수정 후 멈춤. YouTube 다음 재생/재개 시 권한 확인 API에서 최신 영상 ID를 조회. 다른 브라우저에서 이미 재생 중인 영상은 강제로 교체하지 않음.
- 로그인 등 기본 테마와 신규 계정 색은 중립 회색 `#62625F`. 기존에 설정한 포인트 색은 유지. 기존 초기 파란색이며 `updated_at = created_at`인 미수정 기본값만 변경; 과거 저장 기록이 없는 명시적 색 선택까지 완벽히 구분하는 별도 플래그는 없음.

## BGM 저장 구조

| 테이블 | 역할 |
| --- | --- |
| `bgm_assets` | 원본 곡. 최초 업로더 `owner_user_id`, 원본 제목, MP3 Storage 경로/크기 또는 YouTube URL/영상 ID |
| `bgm_library_items` | 사용자별 개인 보관함 연결. `user_id`, `bgm_asset_id`, 개인 이름 `custom_title` |
| `bgm_playlists` | 사용자별 플레이리스트 제목·소유자·페이지 자동 연동 정보 |
| `bgm_playlist_items` | 플레이리스트 곡 연결·순서·별칭 |
| `page_bgm_items` | 페이지 대기 BGM 또는 로그 블록 BGM 연결. `entry_id`로 블록 귀속 |

MP3 실제 파일은 private `bgm-audio` Storage에 저장. 보관함으로 복사하면 같은 `bgm_asset_id`를 참조하며 파일을 재업로드하지 않는다. 동일 MP3를 따로 업로드한 경우 자동 파일 중복 제거를 수행하는 구조는 아니다. 원본 업로더와 현재 보관함 사용자는 서로 다를 수 있다.

## 적용 및 검증

- 선행 SQL: `202609180001_admin_bgm_and_trash.sql` (사용자가 실행 완료 보고).
- 이번 추가 SQL: `202609180002_bgm_edit_and_neutral_theme.sql`. 링크 편집 RPC, 사용 상태 필터 RPC 및 기본 색 변경이 포함되어 반드시 적용 필요. 기존 함수 overload 제거 후 새 함수의 기본 인자로 이전 2인자 SQL 호출도 호환.
- bootstrap `supabase/schema.sql`에도 동일 SQL 추가.
- 격리 PostgreSQL(PGlite)에서 SQL 반복 실행, 일반 사용자/관리자 권한, 링크 변경·개인 이름·참조 유지·권한 실패 롤백, 휴지통 참조 포함 필터, 초기색/사용자색 유지 검증.
- 코드 회귀 테스트는 관리자 메뉴/제목 상태 배치, dialog/API 구조, 최신 YouTube 재생 경로, 중립 기본색을 검사. 실제 DOM 클릭·픽셀·오디오 재생 테스트를 대체하지 않음.
- 최종 자동 검증: 테스트 196개 통과, production build 및 ESLint 통과.
- 이번 세션에는 인증된 브라우저 조작 도구와 로컬 Supabase 환경 변수가 없어 실제 서비스 화면/Storage 연동·YouTube 소리 확인은 수행하지 못함. main 병합은 보류.
