# BGM 관리 편의성 패치 (2026-09-21)

## 사용자 기능

- MP3 파일을 한 번에 최대 50개 선택하고, 업로드 전 각 곡 제목을 일괄 정리할 수 있다.
- 일부 파일만 실패해도 성공한 곡은 유지되며 실패한 곡만 다시 시도할 수 있다.
- 보관함의 여러 곡을 체크박스로 선택해 플레이리스트에 한 번에 추가할 수 있다.
- 플레이리스트 곡은 전용 손잡이로 드래그해 순서를 바꾼다.
- 플레이리스트를 접거나 펼칠 수 있고 접힘 상태는 현재 브라우저에 저장된다.
- 보관함과 플레이리스트에서 곡 이름을 바꿀 수 있다.
- 새 MP3 업로드는 사용자가 선택한 최초 파일명을 별도 보존하고 관리 화면에 표시한다.

## 데이터와 호환성

- `bgm_assets.original_filename`은 저장 경로나 표시 제목과 분리된 변경 불가 원본 메타데이터다.
- 기존 MP3는 과거에 원본 파일명을 저장하지 않았으므로 추측해 채우지 않고 `원본 파일명 기록 없음`으로 표시한다.
- 기존 BGM asset, 페이지 BGM 연결, 플레이리스트 item ID와 곡별 별칭은 그대로 유지한다.
- 일괄 추가와 순서 변경은 승인된 사용자와 본인 플레이리스트만 허용하는 DB 함수에서 원자적으로 저장한다.
- 마이그레이션: `supabase/migrations/202609210001_bgm_management_ux.sql`
